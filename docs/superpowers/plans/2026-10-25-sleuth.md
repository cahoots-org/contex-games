# Sleuth — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `sleuth/` (today a copy of Whispers) into the small-town deduction game: petty crimes happen live, a podcaster interviews residents, pulls footage and logs, and publishes an episode that code judges.

**Architecture:** Code holds every fact. A crime is a `Crime` record staged by code. Evidence is a set of `Record`s with ids (eyewitness memories, a camera clip, log lines, interview statements), each marked `sound` when it traces to the truth. The existing engine spreads talk about the case through Contex minds as it spreads rumors today. Jev picks actions and household covers, and Haiku only phrases lines from records code hands it. The rumor game is deleted in stage 4.

**Tech Stack:** Python 3.12, FastAPI, Contex (MCP), typesafe_sdk (Jev), anthropic (Haiku), pytest + pytest-asyncio, ruff, one static `index.html`.

**Spec:** `docs/superpowers/specs/2026-10-25-sleuth-design.md`. The spec says `examples/sleuth`, but the code lives at `sleuth/` (package `sleuth`). Stage 0 (the copy) is done. This plan covers stages 1–5.

### Task 5: Evidence records and the solvability check

**Files:**
- Modify: `sleuth/case.py`
- Test: `sleuth/tests/test_case.py`

**Interfaces:**
- Consumes: `Crime`, `stage_crime`, `describe` and `Town.new_phase` logs.
- Produces, in `case.py`:
  - `CAMERA_PLACES = ("grocery", "bar", "town hall", "elm street")`. The last is a doorbell camera.
  - `LOG_PLACES = {"gym": "Gym check-in", "bar": "Bar tab closed", "grocery": "Grocery receipt", "library": "Library checkout"}`.
  - `MAX_WITNESSES = 2`, `WITNESS_TRAITS = 2` and `CLIP_TRAITS = ("height", "coat")`.
  - `WITNESS_ACTION = {"steal": "walked off with something", "vandalize": "was bent over something", "sabotage": "was fiddling with something"}`.
  - The evidence record:
    ```python
    @dataclass
    class Record:
        id: str; case: str
        kind: str            # "memory" | "clip" | "log" | "statement"
        place: str; clock: str; text: str
        holder: str = ""     # vid who saw or said it ("" for place records)
        traits: dict[str, str] = field(default_factory=dict)   # what was seen
        who: str | None = None        # a log's named resident
        sound: bool = True            # traces to the truth
        utterance: str | None = None  # memory: its delivered utterance id; statement: source record id
    ```
  - `record_json(r, town) -> dict` returns `{"id", "kind", "place", "clock", "text", "from"}`, where `from` is the holder's name or `""`. It never includes `sound`, `traits` or `who`.
  - `witness_memories(crime, town, routine, rng, ids) -> list[Record]`. Witnesses are residents with `routine.place(w, crime.phase) == crime.place`, excluding the culprit and victim, sampled up to `MAX_WITNESSES`. Each sees `WITNESS_TRAITS` culprit traits drawn by `rng`. The clock is the crime minute ±20, clamped to the phase. The text is `f"Around {clock}, {at(place)}, someone {describe(seen)} {WITNESS_ACTION[t]}."`.
  - `camera_clip(crime, town, ids) -> Record | None`. It exists only if `crime.place in CAMERA_PLACES`. It sees `CLIP_TRAITS` at the crime minute, with the text `f"{clock}, {place} camera: a figure {describe(seen)} {WITNESS_ACTION[t]}."`.
  - `logs(crime, phase_log, town, rng, ids) -> list[Record]`. It makes one record for every (log place, vid) where the place is in that vid's phase list, with the text `f"{label}: {name}, {clock}"`.
  - `suspects(crime, records, town) -> set[str]`. It starts from every resident except the victim. It keeps those whose traits contain every memory/clip `traits`. It then drops anyone named by a log at a place other than `crime.place` who has no log at `crime.place`. In the player's terms, a log elsewhere is an alibi.
  - `make_solvable(crime, records, town, routine, rng, ids) -> list[Record] | None`:
    - If `suspects(...) == {crime.culprit}`, it returns `[]`.
    - Otherwise it adds one late witness. That is the first non-culprit, non-victim resident expected at the place, or any resident. The witness's memory greedily picks the culprit traits that rule out the most remaining suspects, until only one is left.

    - Errors: "There's no open case."; "People here won't share records with you right now." when `reputation.mean(me, all vids) < guarded_at`; and "There's no footage or log for the case here." when nothing applies.
